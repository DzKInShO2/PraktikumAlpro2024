    \subsection{Menghitung Suhu Ruangan}
    \begin{lstlisting}
 #include <iostream>
\end{lstlisting}

    {\Script} ``{\crnfamily \#include <iostram>}'' adalah \textit{header file} yang digunakan sebagai standar masukan dan keluaran dalam bahasa C++ untuk mendeklarasikan dan mendefinisikan {\statement} “{\crnfamily cin}” dan “{\crnfamily cout}”.

    \begin{lstlisting}
 using namespace std;
\end{lstlisting}

    {\Script} “{\crnfamily using namespace std;}” adalah {\statement} yang digunakan untuk mendeklarasikan perintah kepada {\compiler} bahwa file tersebut akan menggunakan seluruh fungsi yang menjadi bagian dari “{\crnfamily namespace std}”.

    \begin{lstlisting}
 float temp;
\end{lstlisting}

    {\Script} ``{\crnfamily float temp}'' adalah {\statement} deklarasi sebuah variabel. Dalam bahasa C++ deklarasi variabel akan mengambil sebuah alamat memori dan membuat variabel yang menunjuk pada alamat tersebut. Oleh karena itu di bahasa C++ sebuah variabel yang dideklarasikan namun tidak diinisialisasi akan bernilai acak karena akan langsung menggunakan alamat memori tanpa mengaturnya ke 0.

    \begin{lstlisting}
 cin >> temp;
\end{lstlisting}

    {\Script} ``{\crnfamily cin >> temp}'' adalah {\statement} {\ioi} yang mengambil masukan dari \textit{standard} {\ioi} {\stream} dan memasukannya kedalam variabel ``{\crnfamily temp}''. Hal ini juga yang mengakibatkan variabel ``{\crnfamily temp}'' tidak diinisialisasikan seperti yang telah dijelaskan sebelumnya karena variabel ``{\crnfamily temp}'' akan langsung digunakan untuk menyimpan masukan.

    \begin{lstlisting}
 return 0;
\end{lstlisting}

    {\Script} ``{\crnfamily return 0;}'' adalah {\statement} keluaran sebuah fungsi yang akan menunjukan kembalian sebuah fungsi. {\Statement} ini juga menandakan akhir sebuah fungsi. Dalam kasus fungsi ``{\crnfamily int main}'' {\statement} ``{\crnfamily return 0;}'' digunakan untuk mengembalikan status eksekusi sebuah program pada akhir program. Bila kembaliannya ``0'' maka program tersebut berjalan tanpa masalah, namun apabila kembaliannya bukan ``0'' maka ada kendala atau kesalahan saat menjalankan program tersebut.
