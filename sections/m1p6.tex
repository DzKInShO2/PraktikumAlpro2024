    \noindent \hspace*{0.75cm}Berdasarkan hasil praktikum pada Modul {\thechapter} tentang \leftmark, dapat diambil kesimpulan bahwa:
    \begin{enumerate}
        \item {
            Algoritma adalah langkah-langkah terstruktur untuk menyelesaikan masalah. {\Pseudocode} adalah deskripsi informal algoritma dalam bahasa manusia. {\Flowchart} adalah representasi visual dari algoritma. Ketiganya membantu dalam perencanaan dan visualisasi solusi sebelum implementasi dalam kode.
        }
        \item {
            Dasar-dasar penulisan program komputer meliputi pemahaman tentang sintaksis dasar suatu bahasa pemrograman, seperti aturan penulisan variabel, pernyataan kontrol aliran dan penggunaan fungsi dasar.
        }
        \item {
            Setiap program yang ditulis dalam bahasa C++ harus memiliki fungsi \inputscript{int main()}, fungsi tersebut berfungsi sebagai \textit{entry point} program. Setiap program yang ditulis dalam bahasa C++ harus memiliki fungsi tersebut kecuali pada saat program di-\textit{compile} dengan opsi \inputscript{-nostdlib} dimana akan menyebabkan program yang ditulis tidak bergantung pada C++ \textit{standard library} yang akan menyebabkan {\header} {\file} seperti \inputscript{iostream}, \inputscript{iomanip} dan sebagainya tidak bekerja serta membuat isi fungsi \inputscript{int main()} dikarenakan fungsi tersebut bukan lagi merupakan \textit{entry point}.
        }
        \item {
            Tipe data menentukan jenis nilai yang bisa disimpan dan dioperasikan dalam program. Contohnya termasuk \inputscript{int}, \inputscript{float}, \inputscript{double}, \inputscript{bool} dan \inputscript{char}. Memahami penggunaan tipe data memastikan integritas dan keakuratan data dalam program. Setiap tipe data memiliki ukuran yang spesifik yang bergantung pada mesin dimana program tersebut di-\textit{compile} misal pada mesin 32-bit ukuran tipe data \inputscript{int} adalah 2 \textit{byte} sedangkan pada mesin 64-bit ukuran data \inputscript{int} adalah 4 \textit{byte}.
        }
        \item {
            {\Typecasting} adalah proses mengubah tipe data variabel dari satu jenis ke jenis lainnya. Ini sering digunakan untuk memastikan konsistensi dalam operasi yang melibatkan tipe data yang berbeda atau untuk mengatasi masalah konversi tipe. {\Typecasting} dapat dilakukan secara eksplisit, di mana pemrogram secara langsung menentukan konversi tipe data, atau implisit, di mana konversi dilakukan secara otomatis oleh bahasa pemrograman.
        }
    \end{enumerate}
