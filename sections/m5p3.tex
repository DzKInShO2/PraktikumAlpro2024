    \subsection{PT. KAP Kereta Api Pemrograman}

    Setelah mengenang masa-masa kuliahnya, singkat cerita, Holil pun lulus dari kuliahnya dan memulai hidupnya sebagai seorang \textit{programmer}. Dia pun merantau ke Jawa untuk mencari pekerjaan. Sesaat sampai di pulau Jawa, Holil kebingungan mencari transportasi yang cocok buat dia cari kerja. Dia mencari di mesin cari hpnya dan menemukan kereta khusus untuk mencari pekerjaan yang dia impikan, yaitu kereta api \textit{programmer}, dimana kereta api ini dikhususkan untuk para \textit{programmer} yang mencari pekerjaan ataupun yang sudah bekerja.

    \inputfigure[n]{res/m5i1.png}{0.7}{Keluaran Bagian 1 Program PT. KAP Kereta Api Pemrograman}{fig:m5:i1}

    Setelah memasukkan jumlah gerbong, gerbong kereta pun terpasang pada lokomotif. Pada gambar di bawah, gerbong A adalah gerbong lokomotif, sedangkan gerbong B dan seterusnya adalah gerbong penumpang dimana angka setelah gerbong adalah jumlah penumpang di gerbong tersebut.

    \inputfigure[n]{res/m5i2.png}{0.4}{Keluaran Bagian 2 Program PT. KAP Kereta Api Pemrograman}{fig:m5:i2}

    Holil kemudian mengecek info dari masing-masing gerbong. Dia pun memilih gerbong mana yang paling enak sehingga dia bisa fokus untuk mengerjakan codingan sambil menikmati pemandangan di dalam kereta.

    Karena holil masih memegang program kereta tadi, jadi dia memesan kursinya sendiri di program tersebut menggunakan fitur tambah kursi.

    Dia bingung memilih jenis kursi apa yang dia gunakan selama perjalanan. Ia baru ingat bahwa ia merupakan member dari Programmer.id, dan dia memiliki poin yang banyak disitu. Jadi, holil memilih kelas RAJA dan duduk di gerbong dengan kelas RAJA yang paling dekat dengan mesin, yaitu gerbong D.

    \newpage

    {\color{white}a\vspace*{-1.5ex}}
    \inputfigure[n]{res/m5i3.png}{0.6}{Keluaran Bagian 3 Program PT. KAP Kereta Api Pemrograman}{fig:m5:i3}

    Ternyata di belakang holil ada orang lain yang tidak paham bagaimana caranya memesan tiket menggunakan program tersebut. Oleh karena itu, holil membantunya memesan tiket. Orang tersebut ingin memesan tiket dengan ketentuan sebagai berikut:

    \begin{enumerate}
        \item Nama: Rijal   Kelas: BISNIS   GERBONG: C
        \item Nama: Dimas   Kelas: EKO      GERBONG: C
        \item Nama: Rafi    Kelas: RAJA     GERBONG: D
    \end{enumerate}

    Namun, tiket untuk dimas dengan kelas EKO tidak bisa memilih gerbong C karena gerbong C itu untuk kelas BISNIS. Oleh karena itu, program meminta holil untuk memasukkan lagi gerbong yang sesuai. Tetapi holil malah memilih gerbong A yang tidak bisa dipilih juga karena merupakan mesin, jadi program meminta holil untuk memasukkan lagi gerbong yang sesuai dan holil pun memilih gerbong B untuk dimas.
    
    \inputfigure[n]{res/m5i4.png}{0.45}{Keluaran Bagian 4 Program PT. KAP Kereta Api Pemrograman}{fig:m5:i4}

    Agar tidak salah-salah, holil pun mengecek daftar penumpang yang sudah memesan tiket dengan info gerbong.

    \newpage

    {\color{white}a\vspace*{-1.5ex}}
    \inputfigure[n]{res/m5i5.png}{0.55}{Keluaran Bagian 5 Program PT. KAP Kereta Api Pemrograman}{fig:m5:i5}

    A-B1-C1-D2- dan seterusnya menandakan berapa banyak orang yang ada di suatu gerbong. Kemudian ditampilkan juga total penumpang masing-masing kelas.

    Ternyata ada salah satu nama penumpang yang salah, yaitu Rafi. Seharusnya nama Rafi ditulis dengan double f. Oleh karena itu, holil memutuskan untuk menghapus rafi dari daftar penumpang dan menambahkan Raffi ke dalam daftar penumpang dengan kelas dan gerbong yang sama.

    Saat ingin menghapus rafi dari daftar penumpang, tangan holil salah menekan keyboard sehingga kelas penumpang yang seharusnya EKO malah diketik EKKO. Holil juga lupa bahwa kelas penumpang dari Rafi adalah RAJA bukan EKO. Holil pun menghapus Rafi dari daftar penumpang dan menambahkan Raffi.

    \inputfigure[n]{res/m5i6.png}{0.48}{Keluaran Bagian 6 Program PT. KAP Kereta Api Pemrograman}{fig:m5:i6}

    \newpage

    Holil pun dimintai tolong oleh orang lain lagi untuk memesankan tiket, kali ini ada 5 orang yang harus dipesankan tiket, yaitu:

    \begin{enumerate}
        \item Nama: Michael     Kelas: BISNIS   Gerbong: C
        \item Nama: Eysar       Kelas: BISNIS   Gerbong: F
        \item Nama: Ayu         Kelas: EKO      Gerbong: B
        \item Nama: Agna        Kelas: RAJA     Gerbong : G
        \item Nama: Kyky        Kelas: BISNIS   Gerbong: F
    \end{enumerate}

    \inputfigure[n]{res/m5i7.png}{0.48}{Keluaran Bagian 7 Program PT. KAP Kereta Api Pemrograman}{fig:m5:i7}

    Ternyata holil terlalu banyak menambahkan gerbong kereta, sehingga ia harus membuang beberapa gerbong, holil pun memutuskan untuk membuang gerbong dari gerbong C. Namun, holil ingin mencoba apa yang terjadi jika ia membuang mulai dari gerbong A.

    \inputfigure[n]{res/m5i8.png}{0.48}{Keluaran Bagian 8 Program PT. KAP Kereta Api Pemrograman}{fig:m5:i8}

    Holil pun melihat sisa penumpang yang ada setelah melepas gerbong C

    \inputfigure[n]{res/m5i9.png}{0.48}{Keluaran Bagian 9 Program PT. KAP Kereta Api Pemrograman}{fig:m5:i9}

    Karena nama holil terhapus setelah melepas gerbong, holil ingin memasukkan namanya lagi ke daftar penumpang. Ia mencoba memesan tiket dengan kelas gerbong RAJA dan BISNIS, tetapi karena gerbong untuk kedua kelas tersebut sudah tidak ada, jadi holil memesan tiket dengan kelas gerbong EKO.

    \inputfigure[n]{res/m5i10.png}{0.48}{Keluaran Bagian 10 Program PT. KAP Kereta Api Pemrograman}{fig:m5:i10}

    Holil pun berangkat menggunakan kereta dan sampai di tujuan yang diinginkan. Holil melamar kerja ke perusahaan X dan berhasil diterima menjadi seorang \textit{programmer} di perusahaan besar tersebut.
