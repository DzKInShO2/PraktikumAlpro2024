    \ilz{}Berdasarkan \reffigure{fig:m3:i10}, didapatkan keluaran program Enkripsi dan Dekripsi. Program tersebut meminta dua masukan berupa teks dan kunci yang akan digunakan untuk menghasilkan teks yang terenkripsi. Program tersebut akan menggunakan dua buah metode enkripsi yakni enkripsi \textit{reverse cipher} dan enkripsi \textit{Caesar cipher}.

    \ilz{}Enkripsi \textit{reverse cipher} akan menampilkan teks yang sudah dimasukan dalam urutan terbalik dari huruf yang paling akhir ke huruf yang paling awal. Sementara itu enkripsi \textit{Caesar cipher} akan menggeser setiap huruf sebanyak kunci yang dimasukan.

    \ilz{}Pada tampilan akhirnya program tersebut akan menampilkan hasil teks yang sudah dienkripsi menggunakan metode \textit{reverse cipher} dan kemudian akan menampilkan juga teks yang sudah dienkripsi menggunakan kedua metode enkripsi \textit{reverse cipher} dan \textit{Caesar cipher}.
\end{indentlevel0}

\subsection{\textit{Blast the Fireworks!}}
\subsubsection{Algoritma}
\paragraph{Meminta masukan kepada pengguna berupa jumlah kembang api dan menunjukannya
            Dalam urutan A...Z sesuai jumlah masukan.}
\paragraph{Meminta kekuatan kembang api seseuai jumlah masukan sebelumnya.}
\paragraph{Meminta masukan berupa nama kembang api yang akan diledakan.}
\paragraph{Melakukan perulangan hingga ditemukan kembang api yang memiliki nama sesuai.
            Bila ditemukan maka akan lanjut ke langkah selanjutnya dan bila tidak, akan
            melompati langkah selanjutnya.}
\paragraph{Melakukan perulangan maju dan mundur sesuai kekuatan kembang api,
            bila ditemukan kembang api yang memiliki jarak ledakan lebih besar maka atur itu
            sebagai jarak ledakan baru. Untuk setiap kembang api yang termasuk dalam jarak
            ledakan maka nilainya akan di atur ke -1 termasuk kembang api terpilih.}
\paragraph{Menunjukan nama kembang api dan daya ledakannya bila daya ledakan bukan -1.}
