    \ilz{}Berdasarkan hasil praktikum pada Modul {\thechapter} tentang {\leftmark}, dapat diambil kesimpulan bahwa:
    \begin{enumerate}
        \item {
            {\Statement} {\control} dan {\looping} merupakan {\statement} yang digunakan untuk memanipulasi atau mengendalikan alur kerja suatu program. {\Statement} {\control} dan {\looping} digunakan untuk mengeksekusi atau menjalankan suatu blok kode baik sekali maupun berkali-kali.
        }
        \item {
            {\Statement} {\control} merupakan {\statement} yang digunakan untuk mengatur alur kerja suatu program dengan cara menjalankan atau melompati suatu blok kode tertentu dalam suatu kondisi yang telah diberikan.
        }
        \item {
            {\Statement} {\looping} merupakan {\statement} yang digunakan untuk mengatur alur kerja suatu program dengan cara mengulangi jalannya suatu blok kode bila suatu kondisi tertentu. Dalam bahasa C++ terdapat tiga tipe {\statement} {\looping} yakni, \textit{for}, \textit{while}, dan \textit{do-while}.
        }
    \end{enumerate}
